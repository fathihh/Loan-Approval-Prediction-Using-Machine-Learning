# Loan-Approval-Prediction-Using-Machine-Learning
The **“Loan Approval Prediction Using Machine Learning”** project focuses on automating and optimizing the loan approval process through predictive modeling. Traditional loan evaluation systems are slow, inconsistent, and often biased due to manual processing. To overcome these limitations, this project uses machine learning to develop a classification model that predicts loan approval outcomes based on applicant data. Using the **Kaggle Loan Prediction Dataset** with around 45,000 records, the team performed data cleaning, handled missing values through imputation, encoded categorical features, normalized numerical data, and removed irrelevant or extreme outlier records for improved model quality. Various models, including Logistic Regression, Decision Tree, and Random Forest, were tested — with **Random Forest emerging as the most accurate**, achieving approximately **92% accuracy** on test data. Key predictors such as **Credit History, Total Income, and Loan Amount** were found most influential in determining approvals. The model ensures balanced precision and recall, minimizing bias across approval and rejection cases. Future enhancements include integrating behavioral data, deploying a web-based real-time prediction system, and experimenting with advanced algorithms like XGBoost and hyperparameter tuning for even greater performance. This project ultimately demonstrates how AI-driven automation can make financial decision-making faster, fairer, and more efficient.
